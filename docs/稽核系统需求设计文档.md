### 1.1 业务场景

高速公路收费稽核系统旨在检测以下逃费行为：

| 逃费类型 | 说明 |
|---------|------|
| **货车套用客车OBU** | 交易记录车辆类型=1(客车)，但图片识别=货车，通过少交通行费逃费 |
| **出入口车辆不一致** | 比对出入口车辆图片，颜色/车型/车纹明显不一致，存在倒换通行卡逃费 |

### 1.2 数据来源

- **源数据表**：`dwd_tolldata.t_waste_en_ex_gantry`
- **站点字典**：`dwd_tolldata.t_md_tollstationdic`
- **关联字段**：`STATION_ID` = `t_md_tollstationdic.ID`

### 1.3 门架数据结构

同一PASSID表示一次完整行程，包含：

| LANETYPE | 说明 |
|----------|------|
| 入口 | 车辆进入高速 |
| 门架 | 车辆路过门架（可有多条） |
| 出口 | 车辆驶出高速 |

## 2. 功能需求

### 2.1 行程聚合

**功能描述**：按PASSID聚合入口-门架-出口记录，生成完整行程

**聚合规则**：
- 同一PASSID = 同一行程
- 按LANETYPE区分交易类型
- 按OCCURTIME排序

**输出字段**：
| 字段 | 说明 |
|------|------|
| passid | 行程PASSID |
| entry_time | 入口时间 |
| entry_station_name | 入口站点 |
| entry_lane_id | 入口车道 |
| entry_vehicle_id | 入口车牌 |
| entry_vehicle_type | 入口车型(1=客车,16+=货车) |
| entry_vehicle_color | 入口车牌颜色 |
| entry_obu_id | 入口OBU |
| entry_media_type | 入口介质类型 |
| entry_image_license | 入口_license.jpg |
| entry_image_trans | 入口_trans.jpg |
| exit_time | 出口时间 |
| exit_station_name | 出口站点 |
| exit_lane_id | 出口车道 |
| exit_vehicle_id | 出口车牌 |
| exit_vehicle_type | 出口车型 |
| exit_vehicle_color | 出口车牌颜色 |
| exit_obu_id | 出口OBU |
| exit_media_type | 出口介质类型 |
| exit_image_license | 出口_license.jpg |
| exit_image_trans | 出口_trans.jpg |
| gantry_count | 门架数量 |

### 2.2 货车套用客车OBU检测

**功能描述**：检测单条记录中货车使用客车OBU逃费

**检测逻辑**：
1. 从交易记录获取 `VEHICLETYPE`（1=客车）
2. 下载 `_trans.jpg` 图片
3. 视觉模型 `VehicleClassifier.classify()` 识别车型
4. `VEHICLETYPE=1` 但 `识别=truck` → 标记可疑

**图片URL格式**：
```
http://{IPADDRESS}/img/data/{LANE_ID}/{date}/{ID}_trans.jpg
```

### 2.3 出入口车辆比对

**功能描述**：比对出入口车辆图片，判断是否为同一辆车

**检测逻辑**：
1. 入口下载 `_license.jpg`
2. 出口下载 `_license.jpg`
3. 比对各项差异

**比对维度**：

| 比对项 | 方法 | 阈值 |
|--------|------|------|
| 颜色 | HSV主色调分析 | 不一致→可疑 |
| 车型 | VehicleClassifier | 不一致→可疑 |
| 车纹 | ResNet50特征余弦相似度 | <0.6→可疑 |

**图片URL格式**：
```
http://{IPADDRESS}/img/data/{LANE_ID}/{date}/{ID}_license.jpg
```

### 2.4 稽核结果管理

**状态定义**：

| 状态 | 说明 |
|------|------|
| PENDING | 待处理 |
| VERIFIED | 已核验正常 |
| SUSPECTED | 可疑 |
| CONFIRMED | 已确认欺诈 |

## 4. API接口设计

### 4.1 行程API
- `GET /api/audit/trips` - 查询行程列表
- `GET /api/audit/trip/{passid}` - 获取行程详情
- `POST /api/audit/trips/aggregate` - 批量聚合行程

### 4.2 稽核API
- `GET /api/audit/suspects` - 查询可疑记录
- `GET /api/audit/suspect/{id}` - 可疑记录详情
- `POST /api/audit/suspect/{id}/process` - 处理可疑记录

### 4.3 统计API
- `GET /api/audit/stats/overview` - 稽核概览统计

### 9.2 EntryExitMatcher修复

问题：`compare()`方法在失败时静默返回`fingerprint_sim: 1.0`，导致假阳性

修复：添加`_comparison_success`字段，失败时返回`fingerprint_sim: 0.0`

```python
# 失败时
result['_comparison_success'] = False
result['fingerprint_sim'] = 0.0

# 成功时
result['_comparison_success'] = True
```
